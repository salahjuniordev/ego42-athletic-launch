# EGO 42 Ignition

Build a high-energy, premium athletic dark-mode landing page for a sports/fitness brand called EGO 42. The design should match the provided high-contrast athletic aesthetic using React, Tailwind CSS, and Lucide icons.

1. Brand Identity & Color Palette

Brand Name: EGO 42

Background: Solid deep black (#0A0A0A).

Primary Accent: High-intensity athletic red (#E50914 / #D61C1C) inspired by the EGO 42 logo.

Secondary/Text Colors: Crisp white (#FFFFFF) for bold titles/branding, soft light gray (#9CA3AF) for body copy.

2. Navigation & Header

Logo (Top-Left): Display EGO 42 in a bold, italicized athletic typography next to a dynamic running-figure icon in red and white.

Nav Links (Top-Right): Home, Programs, Trainers, Contact in clean white text with subtle hover states.

Corner CTA Button: A solid bright red square button in the far top-right corner with a menu/hamburger icon.

3. Hero Section

Background Typography: Display giant, bold, uppercase background text reading "EGO 42" in crisp white, placed behind the central athlete cutout to create a layered 3D depth effect.

Center Graphic Element: A thick, vibrant red circular frame outlined behind the athlete (z-10).

Hero Subject: A high-contrast black-and-white image cutout of a sprinter or high-performance athlete breaking out of the red center circle.

Hero Copy (Bottom-Left):

A sharp, motivating subtext paragraph (e.g., "Push beyond your limits. Train harder, run faster, and conquer your goals with EGO 42.").

A bold "Explore Programs →" CTA link featuring a red right-arrow icon with a smooth hover effect.

4. Sidebars & Interactive UI

Left Vertical Sidebar: A minimal pagination bar with 3 slider dots (top dot active in bright red).

Right Vertical Sidebar: Stacked social media icons (Instagram, X/Twitter, YouTube) in white, separated by a thin vertical line, ending with a Search (Q) icon at the bottom.

5. Layout & Interactivity

Ensure full responsiveness across desktop, tablet, and mobile screens.

Use smooth CSS transitions for buttons, links, and image hovers.

Use z-index layering: Background text on z-0, red ring on z-10, athlete cutout on z-20.
